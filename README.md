# إدخال حزم سهل — Sahel Bundle Keyboard

برنامج صغير وسريع لويندوز يساعد كاشير برنامج **سهل** على إدخال «الحزم» (مجموعات منتجات) بضغطة واحدة.
البرنامج يحفظ تعريفات الحزم، ثم يقوم بكتابة كل صنف وكميته وسعره تلقائياً كما لو كان شخص يكتب على لوحة المفاتيح.

> البرنامج لا يتصل بقاعدة بيانات سهل ولا يعدل أي ملف تابع له؛ هو فقط **يولّد ضغطات مفاتيح قياسية** إلى النافذة النشطة.

---

## التحميل والتشغيل (بدون تثبيت أي شيء)

1. افتح صفحة المستودع على GitHub ← تبويب **Releases**.
2. نزّل `Sahel-Bundle-Keyboard-win-x64.zip` من آخر إصدار.
3. فك الضغط في مكان **قابل للكتابة** مثل سطح المكتب أو المستندات.
   ⚠️ لا تضعه داخل `Program Files` أو أي مجلد محمي، لأن البرنامج يحفظ البيانات بجانب الملف التنفيذي.
4. شغّل `SahelBundleKeyboard.exe` مباشرة. لا يحتاج تثبيت .NET أو أي متطلبات.

## طريقة الاستخدام

1. من تبويب **«الحزم»**: أنشئ حزمة جديدة وأضف الأصناف (كود اختياري، اسم المنتج، الكمية الأساسية، سعر مخصص اختياري)،
   أو استوردها من ملف Excel/CSV عبر زر الاستيراد (يمكن توليد قالب جاهز من نفس التبويب).
2. من تبويب **«التشغيل»**: اختر الحزمة واكتب عدد الحزم المباعة (عدد صحيح موجب).
3. اضغط زر «إظهار وحدة التحكم العائمة» إن أردت أزراراً عائمة صغيرة لا تسرق التركيز.
4. انقر داخل **حقل البحث عن المنتجات في برنامج سهل** ليصبح هو النافذة النشطة.
5. ابدأ بالاختصار العام أو بزر «ابدأ ▶» في الوحدة العائمة. سيظهر عد تنازلي ثم يقوم البرنامج بإدخال كل صنف بالترتيب:
   - يكتب الكود إن وجد وإلا اسم المنتج ← Enter
   - يكتب الكمية النهائية (الكمية الأساسية × عدد الحزم) ← Enter
   - يكتب السعر المخصص إن وجد فقط ← Enter

### الاختصارات الافتراضية (قابلة للتغيير من الإعدادات)

| الوظيفة | الاختصار |
|---|---|
| بدء التشغيل | `Ctrl+Alt+G` |
| إيقاف مؤقت / استئناف | `Ctrl+Alt+P` |
| إيقاف نهائي | `Ctrl+Alt+S` |

- الإيقاف المؤقت يستأنف من **نفس الخطوة بالضبط**.
- الإيقاف النهائي يوقف فوراً حتى أثناء العد التنازلي، لكنه **لا يمكنه التراجع** عن ما كُتب قبل الإيقاف.

## موقع البيانات والنسخ الاحتياطي

- كل البيانات في مجلد `Data` بجانب البرنامج (`Data/data.json`). نسخ مجلد البرنامج = نسخ كل البيانات.
- يتم الحفظ تلقائياً وبطريقة آمنة (ملف مؤقت ثم استبدال) بحيث لا تتلف البيانات عند انقطاع الكهرباء.
- من **«الإعدادات»** يمكنك تصدير نسخة احتياطية كاملة (JSON) واستيرادها مع معاينة وتأكيد،
  ويُنشأ البرنامج نسخة أمان تلقائية من بياناتك الحالية قبل أي استبدال.
- إذا كان ملف البيانات تالفاً، ينقل البرنامج الملف التالف باسم مؤرخ ويبدأ ببيانات فارغة دون المساس بالملف الأصلي.

## مشاكل شائعة

| المشكلة | السبب والحل |
|---|---|
| الضغطات لا تصل إلى سهل | سهل يعمل بصلاحيات مسؤول. شغّل هذا البرنامج **كمسؤول** أيضاً (زر يمين ← تشغيل كمسؤول). |
| رسالة «تعذر تسجيل اختصار…» | الاختصار مستخدم من برنامج آخر (مثل Discord أو برامج الترجمة). غيّر الاختصار من الإعدادات. |
| الإدخال سريع جداً وسهل يفوت أحرف | زد قيمة **التأخير** من الإعدادات (مثلاً 200 مللي ثانية). |
| فقدت بياناتي بعد نقل المجلد | تأكد أن مجلد `Data` انتقل مع البرنامج وأن المجلد قابل للكتابة. |
| ويندوز سمارت سكرين حذّر عند التشغيل | لأن الملف غير موقّع رقمياً. اضغط «More info» ثم «Run anyway». |

## حدود تقنية مهمة

- **قيود الصلاحيات (UIPI):** ويندوز يمنع حقن لوحة المفاتيح لبرنامج أعلى صلاحية. إذا كان سهل يعمل كمسؤول، شغّل هذا البرنامج كمسؤول.
- **F12 محجوز:** لا يمكن استخدام F12 في الاختصارات لأن ويندوز يحجزه للمصحح.
- **الاختبار النهائي على سهل يدوي:** لا يمكن التحقق من التفاعل الفعلي مع سهل إلا على جهاز ويندوز حقيقي؛ راجع `docs/manual-windows-test.md`.

## للمطورين: البناء والنشر من الماك

كل البناء والاختبار والنشر يجري على GitHub Actions (ويندوز) — لا تحتاج تثبيت .NET على الماك:
1. عدّل الكود في Cursor ثم اعمل commit و push لفرع `develop`.
2. تأكد أن workflow ‏**CI** أخضر في تبويب Actions.
3. للنشر: تبويب Actions ← **Release** ← Run workflow ← أدخل إصداراً مثل `v1.0.0`.
   (أو أنشئ tag بنفس الشكل وادفعه).
4. حمّل ZIP من صفحة Releases التي يُنشئها الـ workflow.

التفاصيل في `CONTRIBUTING.md`.

```text
src/SahelBundleKeyboard.Windows         SendInput، نافذة الرسائل، تسجيل الاختصارات العامة
src/SahelBundleKeyboard.App             واجهة WPF عربية RTL + نقطة تركيب الخدمات
tests/                                  xUnit: نواة + بنية تحتية
docs/                                   المعمارية وقائمة الاختبار اليدوي
```
