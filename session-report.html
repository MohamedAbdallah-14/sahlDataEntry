التسلسل المُنفَّذ لكل صنف (كما يتطلبه سهل)

١ كتابة الكود أو الاسم (Unicode)← ٢ Enter← ٣ تأخير عام← ٤ الكمية النهائية (الأساسية × عدد الحزم)← ٥ Enter← ٦ تأخير عام← ٧ السعر المخصص إن وجد فقط← ٨ Enter← ٩ تأخير ثم الصنف التالي

الأرقام بصيغة ثابتة بفاصلة عشرية نقطة بدون أصفار زائدة (2 · 1.25 · 4.5) — لا Ctrl+A ولا Backspace لأن سهل يحدد القيمة القديمة تلقائياً — الكود له أولوية على الاسم — التسلسل مبني كقائمة إجراءات مجردة تُختبر بمحاكيات دون أي ضغطات حقيقية.

محرك التنفيذ (آلة الحالة)

جاهز→ عد تنازلي 0–3ث→ قيد الإدخال→ اكتمل
أثناء الإدخال⇄ إيقاف مؤقت (نفس الخطوة بالضبط)→ إيقاف نهائي فوري
  • منع التداخل: لا يمكن بدء تشغيل ثانٍ أثناء عمل واحد (رفض واضح بالعربية).
  • فحص الإلغاء والإيقاف المؤقت بين كل ضغطة مفاتيح وليس بين الأصناف فقط.
  • تنفيذ غير متزامن على Thread Pool — الواجهة لا تتجمد أبداً؛ الأحداث تعود إلى Dispatcher.
  • الإيقاف النهائي لا يتراجع عن النص المكتوب مسبقاً (موضّح للمستخدم في الواجهة والملفات).

ما تم بناؤه

🧠 النواة — Core (net10.0)

  • نماذج Bundle / BundleItem مع هويات Guid ثابتة وترتيب صريح وتكرار مقصود للصفوف.
  • SequenceBuilder يبني قائمة إجراءات مجردة قابلة للاختبار بالكامل.
  • محرك حالة غير متزامن + بوابة AsyncGate للإيقاف المؤقت الدقيق.
  • محلل اختصارات (Ctrl/Alt إلزامي، رفض F12 المحجوز، كشف التعارضات).
  • تنسيق أرقام Invariant مع تطبيع الأرقام العربية الهندية ورفض الفاصلة العشرية اللاتينية.

🗄️ البنية التحتية — Infrastructure

  • حفظ JSON ذري (ملف مؤقت + استبدال) بترميز UTF-8 يحافظ على العربية.
  • عزل الملفات التالفة أو الأحدث إصداراً بأسماء مؤرخة دون المساس بالمحتوى الأصلي.
  • نسخ احتياطي كامل مع تحقق شامل ومعاينة ونسخة أمان قبل الاستبدال.
  • قارئ/كاتب XLSX يدوي (ZipArchive+XmlReader) وقارئ CSV متوافق RFC-4180 — بلا مكتبات خارجية.
  • سجل دوّار محدود الحجم (دوران بالحجم + حذف بعد 7 أيام) بلا تسجيل لأي منتجات مدخلة.

🪟 تفاعل ويندوز — Windows interop

  • حقن SendInput: أحداث Unicode للنص العربي/الإنجليزي (Surrogate pairs في دفعة واحدة)، Enter بمفتاح افتراضي + Scan code.
  • نافذة رسائل فقط HWND_MESSAGE لاستقبال WM_HOTKEY.
  • تسجيل الاختصارات العامة بـ MOD_NOREPEAT مع تراجع كامل إلى آخر مجموعة صالحة عند أي تعارض.
  • سلوك النافذة العائمة: WS_EX_NOACTIVATE + WS_EX_TOOLWINDOW + TOPMOST + MA_NOACTIVATE.

🖥️ الواجهة — WPF App

  • ثلاثة تبويبات عربية RTL: التشغيل، الحزم، الإعدادات + شارة حالة ملونة ورأس معلومات.
  • شبكة أصناف قابلة للتحرير مع تحقق فوري بالعربية (IDataErrorInfo) وأزرار ترتيب أعلى/أسفل.
  • معاينة استيراد تفاعلية: صفوف صالحة/باطئة بالأحمر + خيار إضافة أو استبدال.
  • مربعات التقاط اختصارات بالنقر ثم الضغط (HotkeyCaptureBox) مع مسح بـ Backspace.
  • وحدة تحكم عائمة قابلة للسحب تعرض العد التنازلي والتقدم ولا تسرق التركيز أبداً.
  • app.manifest: asInvoker افتراضياً + PerMonitorV2 لدقة الشاشات المتعددة.

خط الإنتاج على GitHub Actions (بدون أي أدوات على الماك)

actions/checkout@v4→ setup-dotnet@v4 ‏(10.0.x)→ restore --locked-mode→ build Release (warnings=errors)→ dotnet test (112)→ publish win-x64 single-file→ مجلد محمول + README عربي→ ZIP + SHA256
  • ci.yml: يعمل عند push/PR على main و develop على windows-latest وينتج artifacts جاهزة للتنزيل.
  • release.yml: tag ‏v* أو تشغيل يدوي بإدخال إصدار — ينشئ Tag إن كان يدوياً، وينشر GitHub Release عبر gh CLI مع استبدال assets عند إعادة التشغيل (بلا تكرار)، وصلاحية contents:write فقط.
  • ملفات packages.lock.json لجميع المشاريع ملتزمة والاستعادة المقفلة مُتحقَّق منها محلياً.
